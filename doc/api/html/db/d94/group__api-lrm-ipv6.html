char *  buffer,
uint16_t  size

Converts a given IPv6 address to a human-readable string.

The IPv6 address string is formatted as 16 hex values separated by ':' (i.e., "%x:%x:%x:...:%x").

If the resulting string does not fit in buffer (within its size characters), the string will be truncated but the outputted string is always null-terminated.

Parameters
[in]addressA pointer to an IPv6 address (MUST NOT be NULL).
[out]bufferA pointer to a char array to output the string (MUST NOT be NULL).
[in]sizeThe size of buffer (in bytes). Recommended to use LRM_IP6_ADDRESS_STRING_SIZE.
